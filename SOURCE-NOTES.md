# The House of the Dead Model 2 VR

Local development port of Sega's original arcade **The House of the Dead**, using its **Model 2C** hardware through pinned MAME 0.289. Initial media support is the original `hotdo` revision. The legacy Model 2 Emulator archive named `hotd.zip` contains this revision; MAME's newer `hotd` Revision A is a different program and is not silently accepted.

Local Quest APK and Windows PCVR development builds are prepared. The initial build was installed on Quest 3S and the user reported successful play, with slow emulation/audio and presentation issues. The 0.1.1 update addressed CPU placement, the cabinet sensor strobe, view framing and the original pistol. The 0.1.7 follow-up sets World scale 0.10 by default with uniform 0.01 menu steps and View size 100%, removes grip-button shortcuts and corrects Original pistol hand mirroring. The captured default reticle is Custom22% minimum /75% maximum /6.7m shrink, retaining HUD100%. Software verification and physical acceptance are separate gates; see [validation](docs/validation.md). No GitHub publication has been performed.

The new app uses `com.vrlightgunhub.hotdmodel2`, a separate `hotd_model2_xr` host library, `HOTD_MODEL2_*` environment variables and its own settings/NVRAM/signing key. It does not replace a managed HOTD2 app. The existing third-party Port0r HOTD installer entry is untouched.

Implemented source includes native serial guns and offscreen reload, ROM-fingerprinted original-game readiness/P1/P2/ammo/lives/service/calibration/pricing, cost-aware native Start/credit sequencing with fresh-input guards, solo hand transfer and reversible paired ownership, the common stereo renderer/OpenXR host, purple VR4ALL options and persistence, and Android media/setup validation. Gun choices are Original, Arcade and the unchanged licensed Zapper. Original is a textured pistol extracted at runtime from the user's verified game data; existing saved gun choices remain intact. Common Arcade colors follow logical P1 red/P2 blue; metal details remain intact. Displayed angle 0 applies the established physical -10 degree offset consistently.

Native accepted-shot events drive recoil and the controller haptic path. Read-only observers distinguish committed shots from refunded ammo, reloads and dry fire, and preserve ownership across delayed engine updates. The VR renderer suppresses the verified cabinet lightgun sensor strobe without changing native inputs or state. View size (50–100%) changes scene framing; World scale changes depth, and Panel/HUD distance affects the raster/HUD surface. Unsupported wider-view/game-zoom menu rows are hidden. Android selects the fastest CPUs already allowed to the emulation thread, with a neutral fallback if discovery fails. Semantic HUD separation, complete-route coverage and physical acceptance of the update remain unverified. Native HOTD still carries MAME's `MACHINE_NOT_WORKING` flag.

Supply your own original-revision media, kept packed. The software verifies all 29 payloads by size, CRC32 and SHA1. No game data is supplied. On Quest the current setup accepts `Download/hotdo.zip`, or a verified original-revision legacy `Download/hotd.zip`; the native set name remains `hotdo`. User settings/NVRAM are separate from media.

Run `tools/test.ps1` for executable Python/Java/C++/OpenGL checks. `tools/build-engine.ps1` builds the exact private upstream dependency; `tools/build-quest.ps1 -CheckOnly` lists the real packaging dependencies and assembling requires their actual binaries. All heavy output lives through `build/`, `private/` and `research/` junctions under `D:/VR4ALL-HOTD-Model2-Build`. See [build notes](docs/BUILD.md), [design](docs/design.md), [native evidence](docs/native-evidence.json) and [credits](CREDITS.md).


Reticle controls (current unpublished candidate): **Custom / None** only, with **Reticle min size25%** and **Reticle shrink distance6.0m** as defaults. Missing, malformed, nonfinite or out-of-range saved shrink distances use6.0m independently of panel distance. Explicit valid saved distances (including1.8m) and other settings remain unchanged. The user can tune each game separately. The mathematical size policy, actual panel reference, real aim target, logical-player colors, independent Laser and menu/service pointers are preserved.
