# Development milestone — The House of the Dead Model 2 VR

Original arcade HOTD Model 2C native adapter and real stereo OpenXR hosts for Windows/Quest. The supplied original `hotdo` revision is hash-verified separately from newer Revision A. Native P1/P2 Start/join, actual two-credit pricing, ammo/lives, service and gun calibration phases are derived from the real program and runtime traces. The common VR4ALL options, controls, fresh-input guards, hand ownership, saved settings, Android preparation/media validation and licensed Arcade/Zapper/controller assets are integrated with unique app identity.

This is a local development milestone, not a public release candidate. Full Quest engine/APK and Windows engine/PCVR package, native aim/stereo/audio integration, original gun extraction, accepted-shot feedback, complete routes and physical headset testing remain incomplete or unverified. No game media is included and no publication is authorized.
