# Banner artwork

The right panel uses a crop of Sega's original *The House of the Dead* arcade flyer, archived as [The House of the Dead arcade artwork](https://gamesdb.launchbox-app.com/games/images/132058-the-house-of-the-dead) by LaunchBox. Original game artwork and trademarks belong to Sega.

The left panel follows the existing VR4ALL dark-grid title layout. The flyer is archival artwork, not a screenshot of VR gameplay. No AI-generated game characters or scenes were added.
