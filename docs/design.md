# The House of the Dead Model 2 VR design

Continue the accepted VR4ALL Model 2 architecture for the original 1997 arcade game, independently of existing HOTD/HOTD2 third-party packages. The user requested separate agents for all three remaining Model 2 lightgun games and authorized implementation. No new generic design questionnaire is needed.

The pinned MAME 0.289 commit is `f34f02505e32c1993c6a782b6814232cbfc74e36`. `hotd` is Revision A on **Model 2C**, using i960KB, MB86235 TGPx4 and SCSP audio. The supplied legacy-emulator `hotd.zip` contains the original **hotdo** revision, which is the initial supported revision. `hotd` Revision A and `hotdp` are not implicitly compatible. Separate ROM contracts retain this distinction. Upstream marks all three `MACHINE_NOT_WORKING`; native emulation correctness is a separate gate from successful compilation.

Use the pinned `model2.cpp` HOTD native serial protocol: channel 2 multiplexes P1 Y/X, P2 Y/X low/high bytes; selectors >=8 return offscreen flags. P1 X range 173..596, P2 X 163..596, both Y 87..380; offscreen border uses the native integer-truncated five percent. Trigger bits are IN1 0x01/0x02; IN0 coin 0x01/0x02, test 0x04, service 0x08, start 0x10/0x20, all active low. Reload is an offscreen trigger, never a made-up cabinet button.

Reuse selected licensed Model 2 capture/stereo renderer, OpenXR host, controller/UI/settings and public model modules from the accepted VC2 host. Record every selected source hash. Replace VC2-specific memory readers, weapon tables, camera writes, flash masks and readiness assumptions. Native original-revision evidence now establishes boot/readiness, P1/P2 activation, ammo/lives, service and EEPROM calibration; require its ROM fingerprints before reading any state. Unknown revisions fail closed. Accepted-shot feedback remains suppressed pending a validated cumulative event transport. An explicit diagnostic operator path may exercise native cabinet inputs. Never infer a native joined player from controller ownership or a successful Start pulse.

Target independent Quest 3/3S and Windows OpenXR builds, native stereo geometry/head tracking, original audio, tracked guns, fresh Start/trigger guards, interchangeable solo hand ownership, reversible P1/P2 hand assignment, purple VR4ALL options and persistent settings, and native service/calibration. Only advertise original gun meshes and accepted-shot effects after native evidence. Wider-view memory writes remain unsupported until HOTD-specific validation. Package/application/library/settings identities use `com.vrlightgunhub.hotdmodel2`, `hotd_model2_xr`, `HOTD_MODEL2_*` and `hotd-model2-vr`.

Native Start funding is acknowledgement-based. Keep the request's physical hand and logical seat through a quick tap; observe the actual shared/per-player balance, operator price and free play each update. A distinct 0.15-second coin pulse plus 0.15-second release may be followed only after the native physical-slot counter advances exactly one and accounting balance/remainder/fraction changes. Counter resets, missing acknowledgement, invalid state, tracking/focus loss and the bounded deadline cancel safely. Native balance must meet the current price before Start; a missing credit is never interpreted as one physical coin. One pending request reserves a shared pool until actual native join/debit acknowledgement; held Start retains its original owner. Maximum32 coins and20 seconds bound a request. Dual-to-P2-only preserves native P2 and its existing hand in both layouts, including its own Continue Start.

Source stays small on C:. Compiler output, media staging and research use source `build/`, `private/`, `research/` junctions to `D:/VR4ALL-HOTD-Model2-Build`. Original media stays read-only; validate size, CRC32 and SHA1 and never download game data. No headset install, GitHub publication or edits to sibling ports are authorized here.

Completion gates are explicit: production adapter tests; common host compilation; fresh pinned engine build; verified owned media; original boot/attract/start/join/service; actual stereo/aim/audio/headset acceptance; complete media-free packaging. A native foundation or compiled host alone is not playable VR.
